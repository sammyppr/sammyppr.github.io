# HPの技術
### フロントエンド・バックエンド
- フロントエンドはユーザーが目に見える「表側（クライアント側）」
- バックエンドは目に見えない「裏側（サーバー側・データベース）」

を担当する領域です。

### フロントエンド
- 役割: Webサイトやアプリの操作画面やデザイン、ユーザーが触れるボタンや文字の表示。
- 主な使用技術: HTML、CSS、JavaScript など。
- 特徴: ブラウザ上で動作し、使いやすさ（UI/UX）や見た目の美しさを重視します。

### バックエンド
- 役割: データの保存、ユーザー認証、サーバーやデータベースの管理・処理。
- 主な使用技術: Python、Java、PHP、Ruby、SQL など。
- 特徴: ユーザーからは見えませんが、システム全体の安全・安定稼働を支えます。

### HTML/CSS/JavaScript
フロントエンドで利用される3つの技術は明確に役割が分担されています。
- HTML: Webページの骨組みや文章の構造を作る言語です（例：文字や画像を表示する）。
- CSS: HTMLで作った骨組みに対して、色やフォント、レイアウトなどの見た目を装飾する言語です。
- JavaScript: ページに動きやインタラクティブな機能を与えるプログラミング言語です（例：ボタンをクリックしたときにポップアップを表示する）。

最近ではAIがHPを生成したりもしますが、書けなかったとしても、どんなことが書いてあるか読めるようにしておくと良いでしょう。

# SNS

### SNS
> SNS（ソーシャル・ネットワーキング・サービス）とは、インターネット上でユーザー同士が写真や文章、動画を通じてつながり、交流や情報共有を行える会員制のサービスのことです。

ブラウザやアプリを使って皆さんも日頃から利用しているでしょう。

### SNSの特長
インターネットを通じて人と人をつなぎ、双方向でリアルタイムのコミュニケーションや情報共有ができる点です。

#### 主な特長
- 双方向のコミュニケーション: 「いいね」やコメント、シェア機能でユーザー同士が手軽に交流できます。
- 高い拡散力: 投稿がほかのユーザーにシェアやリポストされることで、短時間で多くの人に情報を届けられます。
- リアルタイム性: 今起きている出来事や最新のトレンドをその場で瞬時に共有・把握できます。
- 属性によるターゲティング: 年齢層や興味・関心に合わせたアプローチが可能です。

### 代表的なSNSとその特長
- LINE: 全世代の9割以上が利用する生活インフラ。知人との連絡や、企業から直接情報を届けるプッシュ型配信に向いています。
- Instagram: 写真や動画による視覚的なアピールが得意。若い世代を中心に、ハッシュタグで情報を検索する「タグる」文化が根付いています。
- X（旧Twitter）: 拡散力とリアルタイム性が非常に高く、短文での情報発信やトレンドの把握に適しています。
- TikTok: Z世代を中心に利用される縦型ショート動画のプラットフォーム。AIによるレコメンドで、フォロワーが少なくても広く拡散する可能性があります。
- YouTube: 全世代で高い利用率を誇る動画共有サービス。検索エンジンとしての側面も強く、投稿が資産として残り続けます。

# マーケティング
### マーケティング
<!--
https://bow-now.jp/media/column/marketing/
-->

- [公益社団法人日本マーケティング協会が34年振りにマーケティングの定義を刷新](https://prtimes.jp/main/html/rd/p/000000002.000122632.html)

#### マーケティングの定義（2024年制定）

（マーケティングとは）顧客や社会と共に価値を創造し、その価値を広く浸透させることによって、ステークホルダーとの関係性を醸成し、より豊かで持続可能な社会を実現するための構想でありプロセスである。

注 1）主体は企業のみならず、個人や非営利組織等がなり得る。
注 2）関係性の醸成には、新たな価値創造のプロセスも含まれている。
注 3) 構想にはイニシアティブがイメージされており、戦略・仕組み・活動を含んでいる。

> 旧定義（1990年）: 企業が主体となり、競争を通じて市場を創造する活動（売れる仕組みづくり）。

### マーケティングとセールスの違い
マーケティングとセールスは、どちらも商品やサービスを顧客に届けるための活動ですが、その役割やアプローチには以下のような違いがあります。マーケティングが「売れる仕組みを作る」のに対し、セールスは「実際に売る」という役割を担っている点が大きな違いです。


#### マーケティング

役割：市場や顧客のニーズを理解し、価値を生み出し、広める仕組みを作ること
アプローチ：製品開発、ブランド戦略、広告、販売促進など、幅広い活動が求められる

#### セールス
役割：すでに存在する商品やサービスを顧客に売り込む直接的な行為
アプローチ：営業担当者が顧客と接点をもち、商品を購入してもらうための交渉や提案を行うことが中心

### 時代と共に変化するマーケティング
デジタル技術の発展により、マーケティングの手法は大きく変わりました。従来の「売ること」に重点を置いた考え方から、顧客視点での価値提供を重視する方向へとシフトしています。

「近代マーケティングの父」と呼ばれるフィリップ・コトラー氏の著書『[マーケティング4.0](https://amzn.asia/d/0goL8ZiI)』を参考にどのように変化しているかを見てみましょう。


### マーケティング1.0-3.0
#### 1960年代以前：製品重視（マーケティング1.0）
この時代は「良いモノを作れば売れる」という、製品中心の考え方が主流。
#### 1960年～1980年代：顧客志向（マーケティング2.0）
企業は市場調査を活用し、ターゲットに適した商品やサービスを提供する「顧客中心」のマーケティングへと移行。
#### 1980年～2000年代：価値重視（マーケティング3.0）
企業は、単なる商品販売ではなく、社会貢献や環境問題への取り組みを通じて、ブランドの理念を発信することが求められる

### マーケティング4.0
#### 2010年以降：自己実現（マーケティング4.0）
スマートフォンやSNSの普及により、顧客は商品やサービスを通じて「理想の自分」を実現したいと考えるようになりました。企業は、顧客の共感を得るためコンテンツマーケティングなどを活用し、双方向のコミュニケーションを重視しています。このように、マーケティングは時代とともに変化し続けています。今後も新しい技術や消費者の価値観の変化に適応しながら、より効果的なアプローチが求められるでしょう。

### マーケティング活動の4つのステップ
1. 市場調査：顧客ニーズの把握
2. 戦略設計：目標に合わせた計画づくり
3. 実施：具体的な行動に落とし込む
4. 評価：結果を分析し改善点を探る


### マーケティングフレームワーク
マーケティングフレームワークとは、マーケティング活動における課題解決や意思決定のための枠組みや手法のことです。

詳しくは説明しませんが、興味ある人は見てみましょう。

[参考：マーケティングフレームワーク14選！使い方や選ぶポイントをまとめて解説](https://bow-now.jp/media/column/marketing_framework/)

### デジタルマーケティング
デジタルマーケティングとは、PCやスマートフォン、SNSなどのデジタル技術を活用したマーケティングの手法です。WebサイトやSNS、アプリなど、多様なデジタルメディアを活用し、施策を実施します。単に自社製品を宣伝するだけでなく、顧客データを分析して戦略を見直したり、最適なタイミングで情報を提供したりすることも含まれます。

### SNSマーケティング
<!-- 
https://www.salesforce.com/jp/blog/sns-marketing/
-->
SNSマーケティングとは、SNSを活用して商品やサービスの認知度を高め、ユーザーとの関係構築や販売促進につなげるマーケティング手法です。

SNSでは、企業が情報を発信するだけでなく、ユーザーの反応やリアルな声を収集し、商品やサービスの改善にも活かせます。

スマートフォンの普及により、消費者は検索エンジンだけでなくSNSからも商品や企業の情報を集めるようになりました。そのため、企業にとってSNSは、認知拡大やファンづくり、購買への導線づくりに欠かせないマーケティングチャネルになっています。

### SNSマーケティングの主な手法
- オーガニック運用：企業アカウントで投稿やコメント対応を継続し、ユーザーとの関係を深める手法
- SNS広告：年齢や興味関心などに合わせて広告を配信し、認知拡大や購入促進につなげる手法
- インフルエンサーマーケティング：影響力のある人物に商品やサービスを紹介してもらい、認知や信頼を広げる手法

### SNSマーケティングのメリット・デメリット
#### メリット
- リアルタイムで情報を伝えられる
- 広告・宣伝費用を抑えられる
- 企業やブランドイメージの向上につながる
#### デメリット
- 炎上するリスクがある
- SNSの運用担当者を設定する必要がある
- ユーザーの属性を分析しにくい(SNSはその匿名性と広範囲なユーザー層が特徴ですが、SNSマーケティングにおいては属性を分析しにくいというデメリットがあります。)

### SNSマーケティングのステップ
1. **投稿**	自社アカウントで継続的に情報を発信し、ユーザーとの接点を増やす
2. **分析**	ユーザーの投稿や反応を収集し、商品改善や施策の見直しに活かす
3. **企画**	ユーザー参加型のキャンペーンを実施し、認知拡大やエンゲージメント向上につなげる
4. **広告**	SNS広告を配信し、ターゲットに合わせて商品やサービスを訴求する
5. **連携**	インフルエンサーの協力を得て、認知や信頼の拡大を図る

# UGC(User Generated Content)

### UGCとは
UGC（User Generated Content）とは、ユーザーが自発的に作るコンテンツのことです。SNSへの投稿、商品の写真、レビュー・口コミなどが代表です。

- [【SNSマーケティングの専門家に聞いた】2分で分かるUGC(1:58)](https://www.youtube.com/watch?v=ZrXeR9oL3_M)

### UGCキャンペーン
UGC（ユーザー生成コンテンツ）キャンペーンとは、顧客やファンに写真・動画・感想などのコンテンツをSNSへ自主的に投稿してもらうマーケティング手法です。

### UGCキャンペーンの代表的な5つの型
| 型                     | 参加者がすること         | ハードル | 向いている目的           | 
| ---------------------- | ------------------------ | -------------- | ------------------------ | 
| 参加・拡散型           | フォロー・リポスト       | 低             | 認知拡大・フォロワー獲得 | 
| ハッシュタグ投稿型<br> | 指定タグを付けて投稿<br> | 中             | 話題化・投稿の蓄積       | 
| 写真・動画投稿型       | 商品や体験の写真を投稿   | 中〜高         | 利用シーンの可視化       | 
| レビュー・口コミ型     | 感想・レビューを書く     | 中             | 検討層への信頼材料       | 
| コンテスト型           | 作品・アイデアを応募     | 高             | 熱量の高いファンの発掘   |
