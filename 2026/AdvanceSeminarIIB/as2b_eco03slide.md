## 1. 経済はインセンティブの連鎖で動いている
### ステークホルダー
企業などの組織が活動を行うことで影響を受ける利害関係者のことを**ステークホルダー**といいます。
- 消費者 (顧客) 
- 従業員
- 株主
- 債権者
- 仕入先
- 得意先

などなど。金銭的な利害関係だけでなく、企業活動を行う上で関わる全ての人のことを言います。

### 会社は誰のもの?
所有者は株主です。

株主の目的は株主利益を最大化したい。つまり株価をあげたい、となります。

### 経営者
株主は経営者に経営を任せます。

経営者は会社の内容について全ての情報を持っていますが、都合の悪いことは株主に対して黙っていたり嘘をつくかもしれない。

株主と経営者の利害は必ずしも一致しません。

### どうする?
> 情報を隠さず、株価を上げる努力をすれば取締役の報酬をあげる

という契約を結べばいい。これが「インセンティブ理論」で実際の契約の内容を考察するのが「契約理論」となる。

### 従業員は?
給料に見合う労働というサービスを会社に提供します。

給料に納得いかなければ手を抜いたり、それなりにしか働かないかもしれません。そして業績が上がらないかもしれません。 (異論は認めます)

### どうする?
会社の業績があがると=株価が上がったときに、従業員が利益を持てるようにすればよいのです。

**ストックオプション**といい、あらかじめ決めた株価で自社株を購入できる権利があります。

### ストックオプション
「今後 5 年間はいつでも自社の株を 1,000 株まで 1 株 1,000 円で購入してもいいですよ」というストックオプションを付与されたとします。


3 年後に 1 株 2,000 円に上昇していれば、そのときに権利を行使し、 1,000 株を 1 株 1,000 円、100 万円で購入し、それを売却すれば、200 万 の売却益が上がるため、100 万円の利益を得ることができます。

すると、従業員も株価を上げるために必死に働くことになります。

### インセンティブの設計は難しい
ただ、逆に業績が悪くなったときには利益を得られず、やる気をなくす可能性もあります。

### スポーツ選手など
インセンティブ契約は普通に行われていますね。

## 2. 忘れるべきコストはとっとと忘れよう
### サンクコスト (埋没費用)
すでに使ってしまって取り返しようがない費用のことを
> サンクコスト (埋没費用)

といいます。

例えば、複数大学受験したときに、進学した大学以外に支払った受験料はもったいないが、取り返しようがなく、忘れるべきです。

### サンクコストの呪い
赤字部門に対して整理したいのだが、これまで投資した金額・時間=サンクコストにとらわれて、決断ができないことを「サンクコストの呪い」 といいます。

もったいないから、やめられない、ということですね。

### 例1
- ある試合やコンサートを観に行こうと思ってチケットを買いました。
- 当日会場に着いたら、チケットを忘れたことに気づきましたが、当日券は売っています。

当日券を買うべきでしょうか?

### 例2
- 数年間交際を続けてきました。
- その間一緒に時を過ごし、高価なプレゼントもあげてきました。
- でも、今疑問を感じ、別れようか悩んでいます。

別れるべきでしょうか?

### サンクコストの例
もったいないと思う人はサンクコストが意思決定にゆらぎを与えています。
- 忘れてきたチケットに払った代金
- 交際継続のために費やしてきたお金・相手のために使ってきた時間

これがサンクコストとなります。

### 判断に影響を与えてしまう
このようにサンクコストに引っ張られると人間は非合理的な判断に走ってしまうことがあります。

> 意思決定をするときにはサンクコストを無視するべきだ

というのが定説だそうです。

### もちろん一律に判断できるものではない
考慮すべきポイントは時と場合によるが、
> サンクコストは忘れるもの

とする経済学思考は覚えておいて良いでしょう。

## 3. 「得意技」を考える思考法
### 魚・鳥狩り
A,B さんがいて、8 時間狩りをしたときにどのくらいとれるかを魚・鳥 で示しています。

|     | Aさん | Bさん | 
| --- | ----- | ----- | 
| 魚  | 16匹  | 24匹  | 
| 鳥  | 2羽   | 12羽  | 

どちらをやらせても B さんの方が上手ですね。これを「絶対優位」といいます。

### 果たしてBさんは
|     | Aさん | Bさん | 
| --- | ----- | ----- | 
| 魚  | 16匹  | 24匹  | 
| 鳥  | 2羽   | 12羽  | 

A さんと手を組むべきでしょうか?

### Aさんと手を組むと損する？
A さんと分担すると確実に足を引っ張られて損をする、とおもっていませんか?

直感的にはそうだと思いませんか?

### 鳥一羽とる間に魚何匹とれる?
|     | Aさん       | Bさん       | 
| --- | ----------- | ----------- | 
| 魚  | 16匹        | 24匹        | 
| 鳥  | 2羽         | 12羽        | 
|     | 鳥1羽=魚8匹 | 鳥1羽=魚2匹 | 

A さんは「鳥 1 羽と魚 8 匹」、B さんは「鳥 1 羽と魚 2 匹」のどちらかを選 ぶしかなく、どちらかを選ぶとどちらかを失う、という関係にあります。 A さんは魚を取った方が効率が良くなります。

鳥 1 羽を選んだときに犠牲にしなければならない
　　「魚 8 匹」「魚 2 匹」
を「機会費用」と呼びます。

### 魚 1 匹とれる間に鳥何羽とれる?
|     | Aさん         | Bさん         | 
| --- | ------------- | ------------- | 
| 魚  | 16匹          | 24匹          | 
| 鳥  | 2羽           | 12羽          | 
|     | 鳥1羽=魚8匹   | 鳥1羽=魚2匹   | 
|     | 魚1匹=鳥1/8羽 | 魚1匹=鳥1/2羽 | 

魚 1 匹の機会費用は A さん「鳥 1/8 羽」、B さん「鳥 1/2 羽」であり、B さんのとる魚の方が高くついています。

### ってことは？
|     | Aさん         | Bさん         | 
| --- | ------------- | ------------- | 
| 魚  | 16匹          | 24匹          | 
| 鳥  | 2羽           | 12羽          | 
|     | 鳥1羽=魚8匹   | 鳥1羽=魚2匹   | 
|     | 魚1匹=鳥1/8羽 | 魚1匹=鳥1/2羽 | 

B さんは魚捕りを A さんに任せて、自分は鳥を捕った方が効率がいいのです。

### 比較優位
相手と比べて比較的得意なものを「比較優位」といいます。
> 絶対優位： 相手よりすぐれているものが優位
> 比較優位：代償となるものを比べて機会費用が小さい方が優位

- 「A さんは魚捕りに比較優位をもつ」
- 「B さんは鳥狩りに比較優位をもつ」

と言えます。

### A さんと組むべきか実際比べてみましょう
A,B さんが単純に 4 時間ずつ魚・鳥をとった場合

|     | Aさん | Bさん | 合計 | 
| --- | ----- | ----- | ---- | 
| 魚  | 8匹   | 12匹  | 20匹 | 
| 鳥  | 1羽   | 6羽   | 7羽  | 

比較優位を考慮して A さんはずっと魚をとり続け、B さんは最初の 2 時 間魚、残り 6 時間で鳥をとると

|     | Aさん | Bさん | 合計 | 
| --- | ----- | ----- | ---- | 
| 魚  | 16匹  | 6匹   | 22匹 | 
| 鳥  | 0羽   | 9羽   | 9羽  | 


### 比較優位を考慮した方がたくさん捕れてる！

|     | A,B4時間ずつ | A魚のみ／B2時間魚、残り鳥 |
| --- | ----- | ----- |
| 魚  | 20匹  | 22匹   |
| 鳥  | 7羽   | 9羽   |

### 比較優位の思考法
ある行動を選択すると失われる、他の選択可能な行動の最大利益を「機会費用」といいます。「逸失利益 (本来得られるべきだったのに、得られなくなった利益)」の方がわかりやすいかも。

サンクコストは忘れるべき費用だけど、機会費用は絶対に忘れてはいけない費用。

それぞれが得意技に特化して協力すると全体の利益が増加することになります。

## 4. 人は合理的なのか 非合理的なのか
### 経済学の前提
経済学は合理的な人間像を前提にしている
- 人は自分の満足度を最大にするために動く (効用の最大化)
- 企業は利潤を最大にするために原材料を調達し商品を生産し販売する (利潤の最大化)

### 情報の非対称性
現実の市場には嘘など情報の非対称性があり、美しい需要と供給の法則はなかなか存在しないため、市場経済の原理が働かない場面がある。

### 人々のふるまい
人々は最大の効用を求めず悲観的な心理状態になり、閉鎖的になることもある。

世の中に合理的ではない結果が溢れるが、人間は完全な合理性をもっていないからだ。これを「限定合理性」という。

### 人間の限定合理性
同じ品質、同じ価格の商品であれば
- ブランド
- 広告のコピー
- デザイン
- キャラクター

などのちょっとした差異によって需要側の行動は変わる。高くても品質以外の要素に惹かれる人も多いはずだ。

半額に下がったおにぎりも、手にとって製造元の名声 (ブランド) を確認し、のりの巻き方をチェックしたりする。価格だけで選択していない。

## 5. グローバル時代に必要な経済学思考
### 資本主義
生産要素と生産手段をだれでも私有でき、生産物を自由に市場で売買して利益を得ることができる大勢のことを言う。つまり、
> 資本主義=市場経済=財産の私有の自由

ということだ。

反対に、生産手段の私有を認めず、すべて国有で生産活動を行う体制を「社会主義」という。

### 比較制度分析
... むずいから、とばしていこう。

日本とアメリカの資本主義市場経済は同じか、というと国によってさまざまな違いがあるが、「経済システムの違いは制度の違いで生まれた」と して分析するのが比較制度分析、という考え方。

ここでいう制度とは仕組みの集まりのことで、法律だけでなく、社会の基礎に横たわっている慣習など社会を作り上げている仕組みのことを指す。

### 比較制度分析 4 つのポイント
1. 資本主義経済システムの多様性を認める
2. 制度のもつ戦略的補完性をとらえる
3. 経済システム内部の制度的補完性をとらえる
4. 経済システムの進化と経路依存性をとらえる

### 日本型資本主義 高度成長期の戦略補完性
終身雇用制度」と「年功賃金制度」も 1940 年代の戦時体制で確立し、 1960 年代の高度成長を経て強化された仕組み
- 新卒で就職すると、定年までその会社に勤務する終身雇用制度
- 毎年昇給していく年功賃金制度
これらは社員から見れば長期的に安定し、ライフプランを立てやすい安全な仕組み。企業からみても、社員を一から育て、長期的に安定した人事管理が可能になる。社員と企業の間で戦略的補完性が存在したことになる。

### 日本型資本主義 高度成長期の制度的補完性
- メインバンク制度
- 終身雇用制度
- 年功賃金制度

は、それぞれが補い合い、支え合い、強固な日本型資本主義を形作ってきた。これらの制度には制度的補完性があったといえる。

(ここ、説明なしでかいてあるな... ま、そういうことにしておこう... ほかにも企業内組合・株式持ち合いが、日本企業にみられた独特の経営手法らしい... あ、メインバンクが同一グループ企業に貸し出す、というとなんかわかるな)

### 日本型資本主義 1980年代から
- 世界的な金融自由化 (国境を越える資金移動の自由化、金利の自由化、日本の金融市場の開放など) により、銀行は政府による保護から競争市場にほうりこまれるようになる。
- 90 年代後半の金融危機で日本の銀行全体の経営が揺らいだ
- 地価下落によって回収できなくなった膨大な不良債権のため、破綻する銀行が続出し、銀行は貸出を大幅に減らし、自己資本の拡大に向かう
- メインバンクとして救済するのではなく、経営危機に陥った取引先企業を切り捨てた

メインバンク制度が徐々に崩れる中、企業も銀行に頼らず株や債権の発行によって市場から資本調達するようになる。すると、メインバンクではなく株主による監視が重視されるようになり、メインバンク 制度は崩れ、制度的補完関係にあった終身雇用や年功制度もうまく機能しなくなってきている。

### 日本型資本主義 1990年代後半以降
強固だった制度の補完性が崩れ、変化して安定するまでの過渡期に現在ある。制度が次の均衡状態へ完全に移行するには 30 年はかかる。

変化の途中として
- 正社員の終身雇用を維持しつつ非正規雇用を増やしている

これが 21 世紀の所得格差の拡大の原因にもなっている。
